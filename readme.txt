Connect WooCommerce with GetYourBill to collect invoicing data and support electronic invoice workflows.

== Description ==

GetYourBill extends WooCommerce with invoicing-related customer fields and integration points for the GetYourBill service.

== Installation ==

1. Upload the `getyourbill` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the `Plugins` screen in WordPress.
3. Install and activate WooCommerce.
4. Open WooCommerce settings and configure GetYourBill.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and active.
